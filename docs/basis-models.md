# Модели Базис-Мебельщика (.b3d)

В файлах технолога Лидии есть не только ведомости (xls), но и сами модели Базиса: около 500 файлов `.b3d` (кухни «К-xxxx Кухня.b3d», отдельные модули «Модели для чпу» T1, T2, Sk1…), плюс `.bir`, `.xbir`, `.ldw`. До 21.10 мы использовали только ведомости; модели не открывали.

## Что выяснено

- Формат `.b3d` читается без Базиса. Разбор лежит в `tools/b3d/b3d.py`, описание формата в шапке файла. Проверено на «К-1974 Кухня.b3d»: файл разбирается целиком (около 4,8 МБ данных, 987 записей справочника фурнитуры).
- Структура модели: Кухня → «Низ», «Верх», «Цоколь» → модуль (T1, Sk1…) → «Корпус», «Фасад», «Опоры», ящики, фурнитура.
- Деталь содержит название, материал (например «ЛДСП EGGER 16мм Белый Премиум W1000 ST9»), толщину, положение и поворот, кромку по каждой стороне, крепёж (евровинты, шканты) с позициями.
- Модули видны как у технолога: «Бок пр вырез Gola», «М планка», «Фас планка в угол», ящики InnoTech Atira (Hettich), лотки, ножки «Ножка кухонная 100мм» ×4 и т. д.
- Размеры детали лежат в сжатом контуре (`Contour`), он пока не расшифрован; размеры берём из комплектовочных ведомостей, положения и состав из модели.

## Что дальше

1. Расшифровать контур детали или сопоставлять с ведомостью по имени и положению.
2. Выгрузить из модели по каждому модулю: габарит, детали с положением (высоты полок, место ящиков, петли), фурнитуру с артикулами.
3. Собрать варианты модулей (по ширине и высоте), сверить с шаблонами `s_*` в прототипе и дополнить библиотеку: угловые, мойка, плита, духовка, пеналы, антресоли, ящики Hettich Atira и Firmax.
