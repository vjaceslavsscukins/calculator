# Дизайн-система CULTURA GROUP

Документ описывает, как выглядит и ведёт себя сайт culturagroup.ru. Его можно перенести в другой проект: токены, шрифты, компоненты и правила ниже не зависят от устройства этого репозитория. Значения взяты из `public/assets/css/style.css`, актуально на 27.10.2026.

## 1. Характер

- **Премиум-люкс, спокойно и дорого.** Образец по духу — whitewill.ru. Сайт продаёт кадром, ремеслом и фактами, а не скидками.
- **Тёмное графитовое поле**, фото крупно, заголовки антиквой капсом, рамки в 1 px вместо заливок.
- **Один бордовый акцент.** Им отмечаются действия (кнопки) и номера. Всё остальное в оттенках серого.
- **Мало текста, много воздуха.** Одна мысль на блок, одна фраза на пункт.
- **Запрещено:** «бесплатно» в кнопках, акции, таймеры, значки доверия, квизы и калькуляторы, FAQ на главной, цены «от» как призыв, иконки-галочки, яркие градиенты, тени-«облака», скругления больше 2 px.

## 2. Цвет

```css
:root{
  --bg:#232322;            /* фон страницы — тон фото-заглушек, светлее чёрного */
  --stone:#3b3b3a;         /* «штукатурка»: серый + фактура камня (stone.jpg) */
  --stone-deep:#2a2a29;    /* глубокая штукатурка, выпадающие меню */
  --text:#f1f0ed;          /* основной текст на тёмном */
  --muted:#a9a8a3;         /* вторичный текст (на штукатурке #c4c3be) */
  --line:rgba(241,240,237,.2);        /* рамки 1 px */
  --line-strong:rgba(241,240,237,.5); /* рамки кнопок */
  --light:#ebe8e3;         /* светлые вставки: форма, карточка проекта */
  --accent:#7d1e2b;        /* фирменный бордо: заливка кнопок */
  --accent-hover:#9a3246;
  --accent-bright:#b32d47; /* бордо для тёмного фона: номера 01, 02…, точка в слогане */
  --rose:#e0aab6;          /* мелкие подписи-метки на тёмном (eyebrow, .label) */
}
/* светлая вставка: цвета меняются местами */
.light{--text:#262625;--muted:#666663;--line:#d3d3cf;--line-strong:#8f8f8a;--rose:#7d1e2b;background:var(--light);color:var(--text)}
```

| Цвет | Где | Где нельзя |
|---|---|---|
| `--accent` `#7d1e2b` | заливка главной кнопки, бордо внутри светлых вставок | мелкий текст на тёмном (не читается) |
| `--accent-bright` `#b32d47` | номера 01, 02…, точка в «Сделано с культурой.», черта под названием плитки | длинный текст |
| `--rose` `#e0aab6` | метки капсом над заголовком («Культура Стандарт») | кнопки, заливки |
| серый логотипа `#545452` | логотип на светлом фоне | фон |

Контраст: основной и вторичный текст проходят WCAG AA (не ниже 4.5:1). Бордовые номера дают около 3:1. Это решение владельца, номера только дублируют порядок.

## 3. Шрифты

| Роль | Шрифт | Начертание | Как |
|---|---|---|---|
| Заголовки | **Prata** (антиква с тонкими засечками) | 400, одно начертание | капсом, `letter-spacing:.005em` |
| Текст, кнопки, меню | **Golos Text** | 400 / 500 / 600 | обычный регистр; кнопки и метки капсом с разрядкой |

Шрифты лежат на своём хостинге (woff2, отдельно кириллица и латиница), без Google Fonts.

```css
--f-head:"Prata","Times New Roman",Georgia,serif;
--f-body:"Golos Text",system-ui,-apple-system,"Segoe UI",Roboto,Arial,sans-serif;
```

### Шкала

| Элемент | Размер | Заметки |
|---|---|---|
| Заголовок первого экрана | `clamp(30px,4.3vw,72px)` | 2 строки, вторая со сдвигом вправо `clamp(0px,4vw,76px)` |
| Слоган блока («Сделано с культурой.») | `clamp(30px,3.6vw,60px)` | в одну строку на компьютере |
| H2 | `clamp(25px,3.8vw,56px)` | капсом, `line-height:1.1` |
| Подзаголовок-строка | `clamp(18px,1.6vw,26px)` | Prata, обычный регистр |
| H3 / пункт | `clamp(20px,1.9vw,26px)` | Prata |
| Лид | `clamp(17px,1.5vw,20px)` | `line-height:1.65`, ширина до 58ch |
| Текст | 17px | `line-height:1.65` |
| Метка (eyebrow) | 12.5px | Golos 500, капсом, `letter-spacing:.16em`, `--rose` |
| Номер 01, 02… | 12–13px (крупный в списках: `clamp(28px,3vw,44px)` Prata) | `--accent-bright` |
| Цифры-факты (5000+) | `clamp(44px,6vw,92px)` | Prata, `lining-nums` |

Ловушка: у Prata тонкие засечки и «крышечки» над Й и Ё. Если заголовок появляется через `clip-path`, верх обрезки должен быть отрицательным: `inset(-30% 0 …)`, иначе верх букв срежется.

## 4. Сетка и отступы

```css
--max:1360px;                 /* ширина контента */
--pad:clamp(18px,4vw,60px);   /* поля слева и справа */
--header-h:84px;              /* высота шапки */
--r:2px;                      /* скругление: почти прямые углы */
--ease:cubic-bezier(.16,.68,.3,1);
.section{padding-block:clamp(64px,9vw,136px)}
```

- Переломы: 1180 px (меню сворачивается в бургер), 900/860 px (двухколоночные блоки в одну), 760 px (телефон).
- Ничего не должно давать горизонтальную прокрутку на 320–1920 px.

## 5. Компоненты

**Шапка.** Фиксированная, полупрозрачная `rgba(35,35,34,.9)` с размытием 14 px, рамка 1 px снизу. Логотип слева, меню, телефон, бордовая кнопка «Обсудить проект». Подчёркивание пункта меню выезжает слева, цвет `--rose`.

**Кнопки.** Высота 56 px, поля 34 px, рамка 1 px, скругление 2 px, текст Golos 600 капсом с разрядкой.
- Главная (`.btn--solid`): заливка `--accent`, при наведении заливка `--accent-hover` выезжает слева.
- Второстепенная: прозрачная с рамкой `--line-strong`, при наведении светлая заливка выезжает слева, текст темнеет.
- Ссылка-действие (`.link`): капсом, 13px, линия снизу.

**Первый экран.** Фото на весь экран, сверху лёгкое затемнение, снизу длинное плавное затемнение (почти половина высоты) в цвет фона, без видимого края. Заголовок в 2 строки, подпись, две кнопки. На телефоне отдельное вертикальное фото `<имя>-m.jpg`.

**Галерея категорий.** Весь блок с заголовком помещается в один экран (высота `100svh − шапка`).
- 6 одинаковых плиток: на компьютере 3 × 2, на телефоне 2 × 3.
- Фото на всю плитку (`object-fit:cover`), снизу затемнение под подпись, рамка 1 px `--line`.
- Подпись: номер `--accent-bright` с лёгкой тенью, название Prata капсом, короткая бордовая черта.
- Наведение: внутри проявляется тонкая рамка-паспарту (отступ 12 px), фото медленно приближается до 1.06, подпись поднимается на 6 px, черта вытягивается.
- Если в фото по краю пустая стена, фото обрезается по краю мебели. Кадр не сдвигается через `object-position`.

**Заголовок блока с подписью.** Слоган в одну строку, под ним строка Prata и лид. Ширина подписи равна ширине заголовка: `.gal-head{width:fit-content}`, а у лида `width:0;min-width:100%`.

**Цифры-факты.** Ряд из 4 ячеек в рамке 1 px с вертикальными разделителями; на телефоне 2 × 2. Цифры набегают от нуля при появлении.

**Шаги и проверки.** Сетка по 4 (или 3) колонки, тонкая линия сверху; номер, заголовок Prata, одна-две строки текста. Список процесса: крупный номер Prata слева, справа заголовок и текст, разделители 1 px.

**Широкое фото блока.** Заголовок в одну строку, под ним фото в пропорции 2:1 по ширине контента (на телефоне 4:5).

**Штукатурка (`.dark`).** Фон `--stone` с фактурой камня, края растворяются в фон маской-градиентом, резкого шва между блоками нет.

**Светлая вставка.** Форма заявки и карточки на светлом `--light`: внутри цвета меняются местами, кнопки остаются бордовыми.

**Форма.** 2 поля в ряд (имя, телефон), город, способ связи кнопками-переключателями, комментарий по желанию, согласие на обработку данных, бордовая кнопка во всю ширину.

**Заглушки фото.** Тихий градиент `#333332 → #2b2b2a`. В галерее без значка и подписи. Заглушка не должна выглядеть как ошибка.

## 6. Движение

- Анимируем только `transform`, `opacity`, `clip-path`, `scale`. Кривая `--ease`, длительность 0.6–1.8 s, ничего не прыгает.
- **Первый экран:** фото медленно «оседает» из лёгкого приближения, заголовок выезжает построчно, затем кнопки; лёгкий параллакс фото при прокрутке.
- **Появление при прокрутке:** заголовки выезжают снизу из-под маски, текст проявляется с подъёмом на 26 px, фото открываются шторкой сверху вниз с уменьшением с 1.2 до 1. Соседние элементы идут волной с шагом 0.09 s.
- Проверка появления по положению элемента, а не через `IntersectionObserver`: он не видит элемент, полностью скрытый `clip-path`. Если скрипт не сработал, через 5 секунд всё показывается само.
- Шапка прячется при прокрутке вниз и возвращается при прокрутке вверх. Есть плавный уход со страницы.
- При `prefers-reduced-motion` движение отключено.

## 7. Фото

- Только реальные работы. Рендеры и сгенерированные интерьеры не выдаём за проекты.
- От 2000 px по длинной стороне, без чужих логотипов, QR-кодов и лиц клиентов.
- Имя файла = место на сайте (`hero`, `dir-kuhni`, `proizv-team`…), вертикальный вариант для телефона `<имя>-m.jpg`.
- Ссылка на фото содержит версию по содержимому файла (`?v=хэш`), поэтому замена фото обновляется у всех сразу.
- Цвет фото не приглушаем: кадр должен быть сочным.

## 8. Тексты

- На «вы», тепло и по-человечески, полными связными предложениями.
- Факты вместо эпитетов. Никаких «уникальный», «идеальное решение», «не просто X, а Y».
- Кавычки «ёлочки», длинное тире с пробелами, неразрывный пробел после коротких предлогов.
- Пишем «производство», не «цех».
- На каждом экране понятное следующее действие: «Обсудить проект» или быстрая связь.

## 9. Логотип

Жирный гротеск **cultura** и рукописное *group*. На тёмном белая версия, на светлом серая `#545452`. Фирменный квадрат: белый логотип на чёрной штукатурке, из него взята фактура `stone.jpg`.

## 10. Проверки перед выкладкой

- Слова в заголовках не рвутся на ширинах 320–1920 px.
- Нет горизонтальной прокрутки.
- Контраст текста не ниже WCAG AA.
- Новый анимированный блок добавлен и в список появления в скрипте, и в правила скрытия в CSS, иначе он останется невидимым.

## 11. Как применять к калькулятору КП (дополнение для `kp-calc`)

Разделы 1–10 описывают сайт. Портал — рабочий инструмент менеджера: таблицы, формы, много цифр. Поэтому берём **токены, шрифты, цвет и характер**, но плотность и движение подстраиваем под работу. Коммерческое предложение — документ для клиента, в нём фирменный стиль сайта в полную силу.

### 11.1. Портал (реестр, карточка клиента, калькулятор, настройки)

- **Цвета и шрифты — те же токены** из разделов 2–3. Фон `--bg`, рамки 1 px `--line`, один бордовый акцент `--accent` для главного действия на экране («Сохранить расчёт», «Собрать КП»). Скругление `--r: 2px`.
- **Тема:** по умолчанию тёмная, как сайт. Таблицы калькулятора и формы — на светлой вставке `.light` (`--light`): длинные столбцы цифр на светлом читаются лучше и печатаются без переделки.
- **Prata** — только заголовки экранов и названия клиентов и расчётов, капсом. Всё рабочее (таблицы, поля, подписи, цифры) — **Golos Text**. Цифры в таблицах моноширинные: `font-variant-numeric: tabular-nums`, выравнивание по правому краю, разряды через неразрывный пробел (`125 400 ₽`).
- **Плотность:** текст 15 px, строки таблицы 40 px, поля ввода 40 px, кнопки 44 px (на планшете не меньше 44 px). Крупная шкала из раздела 3 для портала не нужна. Ширина контента до 1600 px: калькулятору нужна ширина.
- **Кнопки:** главная — бордовая заливка, второстепенная — рамка `--line-strong`, текст капсом с разрядкой, как на сайте. На одном экране одна бордовая кнопка.
- **Состояния:** ошибки и предупреждения — `--accent-bright` текстом и рамкой, без красных заливок. Исправленное вручную количество — метка `--rose` и исходное число из PRO100 рядом серым. Себестоимость и маржа (видит только руководитель) — отдельный столбец с подписью-меткой.
- **Движение:** без анимаций появления, шторок и параллакса из раздела 6. Только короткие переходы 0,15–0,2 s на наведение и раскрытие. `prefers-reduced-motion` соблюдаем.
- Запрет из раздела 1 «квизы и калькуляторы» относится к сайту для клиентов, к внутреннему порталу не применяется.

### 11.2. Коммерческое предложение (PDF и ссылка для клиента)

- Полный стиль сайта: Prata капсом в заголовках, метки `--rose`/бордо, номера изделий 01, 02… цветом `--accent-bright`, крупные рендеры, много воздуха, одна мысль на блок.
- Печатная версия (PDF) — на светлом фоне (`.light`): дешевле печатать и привычнее подписывать. Экранная версия по ссылке — тёмная, как сайт. Вёрстка одна, меняются только токены.
- Тексты — по разделу 8: на «вы», факты вместо эпитетов, «производство», а не «цех». Никаких «акция», «только сегодня», цен «от».
- Рендеры подписываются «Визуализация, возможны отличия» (раздел 7: сгенерированные интерьеры не выдаём за реальные работы).
- Логотип по разделу 9: белый на тёмном, серый `#545452` на светлом.

### 11.3. Что нужно от владельца

- Файлы шрифтов Prata и Golos Text (woff2, кириллица и латиница) и логотип в SVG — из репозитория сайта.
- Фактура `stone.jpg`, если хотим «штукатурку» на экране входа и в КП.
