1. Войти владельцем → «Прайсы» → «Петли» → «Загрузить прайс» → выбрать любой Excel с ценами → «Показать изменения» (ничего не применять, если не нужно).
2. Открыть любой расчёт: единицы м²/м.п. у строк PRO100, в поле артикула напечатать «W960».
3. Под менеджером поставить скидку 6 % — должно появиться «поставит руководитель», расчёт не сохранится.
4. Кнопка ☰ слева вверху — меню сворачивается.
5. «Коэффициенты» — внизу два новых поля лимита скидки (5 и 15).
