# Спецификация (Приложение №2): образец салона

Источник: заполненное Приложение №2 к договору (кухня, 2026). Персональные данные клиента сюда не переносим. Это пример от владельца: в портале спецификация будет в стиле CULTURA GROUP, состав полей можно менять.

## Шапка

- «Приложение №2 к договору оказания услуг по изготовлению под заказ корпусной мебели № К-NNNN от ДД.ММ.ГГГГ»
- ФИО клиента, контакт, адрес
- дата договора, дата подписи
- дизайнер (менеджер)

## Блоки по частям изделия

Одинаковый набор из 7 строк повторяется для каждой части: **верхние модули, фасады со стеклом, антресоли, нижние модули, пеналы**.

| Поле | Пример |
|---|---|
| Фасад (цвет, артикул, толщина, материал, тип фрезеровки) | Массив ясеня / фрезеровка «Берта» / цвет NCS S 0500-N |
| Отделка матовый/глянец | матовая |
| Обратная сторона фасада | Массив ясеня / цвет NCS S 0500-N |
| Направление текстуры | вертикально |
| Корпус (цвет, артикул, производитель) | Egger ЛДСП W1000 ST9 Белый Премиум |
| Задняя стенка (ХДФ/ЛДСП, цвет) | ХДФ белый |
| Ручка (тип, кол-во, артикул, цвет) | Ручки выбираются клиентом / заглубление дна на 20 мм |

Пустая часть (например, антресоли без заполнения) остаётся в бланке пустой.

## Отдельные строки

- Фасадные карнизные планки (материал, цвет, толщина, фрезеровка)
- Фасадные боковины (наличие, материал, цвет, отметить на эскизе)
- Столешница (цвет, материал, артикул) — например Hanex 38 мм ST-102; постформинг/кромка; стыковка (еврозапил/планка)
- Плинтус (цвет, артикул, материал)
- Стеновая панель (артикул, цвет)

## Фурнитура

Ящики (выдвижение, цвет боковин, тип, производитель, кол-во) · Петли (производитель, кол-во) · Подъёмники · Газлифты · Лоток · Поддон · Сушка · Бутылочница · Выкатные корзины · Прочая фурнитура. Пример: «Firmax Newline (белый) — 5 шт», «петли Blum с доводчиком 48 шт», «Aventos HK — 1 шт».

## Длинномеры и прочее

Карниз, пилястры, световая планка (тип, цвет, патина) · Подсветка (длина в м.п., тип выключателя) · Вентиляционные решётки · Цоколь (артикул, цвет, высота, материал) · Алюминиевая рамка для фасада · Стекло для полок · Стекло для фасадов · Прочие декоративные элементы.

## Подвал

- Условия: подъём на этаж при отсутствии грузового лифта — платно на месте; установка и подключение подсветки, техники и сантехники — платно по месту.
- Стоимость товара (итог, руб.)
- «Со спецификацией согласен» — подпись.

## Что это значит для портала

- Спецификация строится по **частям изделия** (верх, низ, антресоли, пеналы, фасады со стеклом), а не по строкам калькулятора. Значит, в расчёте у материала фасада и корпуса должна быть привязка к части, а у части — свой набор: фасад, отделка, обратная сторона, текстура, корпус, задняя стенка, ручка.
- Многие поля — описательные (фрезеровка, NCS-цвет, направление текстуры), их нет в прайсе. Менеджер заполняет их в расчёте или в спецификации; значения по умолчанию подтягиваются из выбранного материала.
- Фурнитура в спецификации — текстом с количеством; количество берётся из калькулятора.
- Номер договора (К-NNNN) и даты — из карточки договора.
