# «Калькулятор КП» как продукт для других мебельных компаний

Ноябрь 2026. Основа — исследование рынка (конкуренты, цены, объём, право; источники в конце) и то, что уже построено в портале CULTURA. Цифры с пометкой **[оценка]** — расчёт, а не факт; их надо проверить интервью с салонами.

## 1. Коротко

- **Ниша есть, прямого аналога всей цепочки в России нет.** Рынок разбит на куски: программы проектирования с модулем «салон» (Базис-Салон, К3), облачные планировщики (PlanPlace, Bplanner, Prodboard), мебельные CRM (Бизнес в Плюсе, AI-Мебельщик), конструкторы КП ссылкой (SalesPilot, КпДок). Цепочку **«проект из любой программы → расчёт по своим прайсам с наценками → продающее КП ссылкой с отслеживанием → спецификация и договор»** целиком не закрывает никто.
- **Размер — хороший бизнес для маленькой команды, не «единорог».** В России 15–25 тыс. компаний продают мебель на заказ с проектом и сметой, из них 5–10 тыс. с салоном и 2+ продающими сотрудниками **[оценка]**. Достижимо за 3 года: 100–400 платящих компаний × 8–12 тыс. ₽/мес = **10–55 млн ₽ выручки в год [оценка]**.
- **Главная боль покупателя и главный риск продукта — ввод проекта.** Все рисуют в разном (PRO100, Базис, К3, bCAD, SketchUp) или считают руками. Кто решит «загрузил проект из любой программы — получил смету по своим прайсам» — тот и выиграет. Это и есть наш центральный продукт, а не КП.
- **Самый сильный канал — фабрика, которая раздаёт инструмент своим дилерам** (платит фабрика, дилеры получают готовый прайс фабрики). CULTURA — эталонный клиент и кейс с цифрами.
- **Модель — тариф на компанию с лимитом мест + разовое подключение + пакеты рендеров.** Ориентир: «Салон» до 5 мест ~7 900 ₽/мес, подключение 30–150 тыс. ₽.
- **Делать отдельное юрлицо и подавать в реестр отечественного ПО** — освобождение от НДС на лицензии/SaaS и доверие покупателей; конкуренты не захотят отдавать себестоимость «соседней фабрике».

## 2. Что продаём (позиционирование)

**«От проекта до КП, которое клиент открыл и утвердил, — за 15 минут. По вашим прайсам, в вашем стиле.»**

Для кого: салон мебели на заказ (кухни, шкафы, гардеробные) с 2–10 менеджерами-дизайнерами, средний и премиум сегмент; фабрики с дилерской сетью.

Что получает собственник:
- менеджер считает быстрее и без ошибок (единые прайсы и наценки, менеджер не видит себестоимость);
- КП, которое продаёт (страница по ссылке, PDF, рендер, «Утвердить» / «Задать вопрос»);
- видно, что происходит: сколько КП ушло, кто открыл, кто утвердил, у кого «зависло», маржа;
- новый прайс поставщика — загрузил файл и сразу видишь, какие действующие КП подорожают.

Что отличает от конкурентов:
| | Мы | Базис-Салон / К3 | PlanPlace, Prodboard | Мебельные CRM | Конструкторы КП |
|---|---|---|---|---|---|
| Проект из любой программы | **да (цель)** | только своя | только свой планировщик | нет | нет |
| Расчёт по своим прайсам с наценками, себестоимость скрыта | **да** | да | частично | частично | нет |
| КП ссылкой с отслеживанием и кнопками | **да** | нет | нет | частично | да |
| Рендер из эскиза | **да** | свой 3D | свой 3D | у части | нет |
| Спецификация, договор | **да / в работе** | да | нет | частично | нет |
| Облако, без установки | **да** | нет | да | да | да |

## 3. Главная боль: ввод проекта (как автоматизировать)

Сейчас расчёт держится на одной вещи — тексте, который менеджер копирует из PRO100, и названиях строк вида `ЛДСП_верх`. Это хрупко: у каждой мастерской свои названия, своя разметка, фурнитура заложена по-разному, кто-то вообще считает в Excel.

**Решение — «единый формат проекта» + адаптеры + сопоставление, которое учится.**

```
 PRO100 (текст/CSV)  ─┐
 Базис (XML/CSV)      ─┤                    ┌─ сопоставление с прайсом компании ─┐
 К3, bCAD (Excel/CSV) ─┼─► адаптер ─► ПРОЕКТ ┤  (словарь синонимов, запоминает    ├─► расчёт движком ─► КП
 Excel-шаблон         ─┤   (единый формат:   │   выбор, нечёткий поиск, ИИ —      │
 PDF/скриншот отчёта  ─┤    материалы, м²,   │   только подсказка)                │
 Быстрый ввод модулями─┘    м.п., шт, фурнит.)└────────────────────────────────────┘
```

1. **Единый формат проекта.** Внутри — не «строки PRO100», а нейтральный список: «плитный материал корпуса верх 6,42 м²», «фасад низ 3,6 м²», «петли 14 шт», «столешница 3,2 м.п.»… с указанием, откуда пришло. Движок считает только из него. Это небольшая переделка: сейчас роль строки задаёт название PRO100, будет задавать поле «что это».
2. **Адаптеры по программам** (по порядку надёжности):
   - **PRO100** — уже есть (вставка текста); добавить загрузку файла отчёта CSV/TXT.
   - **Базис-Мебельщик** — экспорт спецификации в XML с документированной структурой (её уже читают обработки 1С). Самый надёжный формат на рынке — делать вторым.
   - **К3, bCAD, SketchUp** — отчёты в Excel/CSV; адаптер настраивается по образцу файла от пилотного клиента («какая колонка — материал, какая — количество»), настройка сохраняется для компании.
   - **Excel-шаблон** — для тех, кто считает руками: наш шаблон «по позициям».
3. **Сопоставление, которое учится.** Экран «из файла пришло → позиция прайса»: в первый раз менеджер выбирает, дальше подставляется само для всей компании (сейчас запоминается только для одного пользователя — расширить до компании). Нечёткий поиск по артикулу и названию уже есть. ИИ (языковая модель) — только подсказывает вероятное соответствие, решение за человеком.
4. **Быстрый ввод модулями — «прикидка» на замере.** Без программы: длина низа и верха в метрах, число фасадов по типам, ящиков, столешница, мойка, подсветка — ориентировочная цена за 3 минуты. Для первого разговора с клиентом и для тех, кто не рисует.
5. **PDF и скриншоты отчётов → черновик через ИИ с распознаванием изображений.** Для печатных таблиц в 2026 работает хорошо; строки, в которых модель не уверена, подсвечивать. С рукописного эскиза без размеров смету не получить — честно говорим, что это черновик.
6. **Позже — свой конфигуратор в браузере** из параметрических модулей (в репозитории уже есть задел «Конструктор кухонь» с 3D). Сначала для фабрик с типовыми модулями: тогда расчёт точный «по деталям», а рисунок сразу идёт в КП и рендер.

Что это даёт: подключение нового салона — не «перепишите свои названия под нас», а «загрузите один проект, мы сопоставим, дальше само». Это и снижает стоимость подключения, и становится главным аргументом продаж.

## 4. Что доработать в продукте, чтобы продавать другим

Сейчас портал сделан под одну компанию. Для продукта нужно (по важности):

**Обязательно до первых платящих клиентов**
1. **Несколько компаний в одной системе.** У каждой — свои пользователи, клиенты, прайсы, наценки, КП, бренд. Технически: «компания» во всех таблицах и в каждой проверке доступа (сейчас проверка по роли и городу — расширяется на компанию). Тесты на «чужая компания не видит ничего» — как уже есть для менеджеров.
2. **Регистрация компании и онбординг:** пробный период, мастер «загрузите прайс → наценки → логотип и тексты КП → пригласите менеджеров → первый проект».
3. **Наценки по группам** (у CULTURA одна на всё, у других — на фурнитуру одна, на плиту другая) и **разные виды изделий** (гардеробные, прихожие).
4. **Конструктор КП в стиле компании:** логотип, цвета, обложка, факты «почему мы», условия. Сейчас стиль CULTURA вшит в шаблон.
5. **Тарифы и оплата:** счёт и акт для юрлиц, рекуррентная оплата картой (ЮKassa / CloudPayments / Т-Касса) с онлайн-кассой; лимиты мест и рендеров.
6. **Надёжность:** ежедневные копии базы с проверкой восстановления, мониторинг и оповещение о падении, журнал ошибок, страница статуса. Обязательства (SLA) в оферте.
7. **Юридическое:** оферта; поручение на обработку персональных данных (мы — обработчик для салонов); уведомление в Роскомнадзор; хранение в России (Timeweb подходит); срок жизни ссылок КП.

**Сильно помогает продавать**
8. Адаптер Базиса и загрузка отчётов файлом (см. раздел 3).
9. Разбор прайсов поставщиков через ИИ (PDF и Excel в любом виде → строки «артикул — цена»): снижает стоимость подключения — главную статью затрат.
10. Интеграции: Битрикс24 и amoCRM (сделка, стадия, ссылка на КП), позже 1С.
11. Варианты в одном КП («Эконом / Оптимум / Премиум») и декоры с картинками.
12. Мобильный вход для менеджера (посмотреть КП, ответить клиенту с телефона).

**Для фабрик**
13. Режим «фабрика + дилеры»: единый прайс фабрики, дилер ставит свою наценку, фабрика видит отчёт по КП и заказам дилеров; белая метка (бренд фабрики).

## 5. Модель оплаты

| Тариф | Кому | Что входит | Цена [ориентир] |
|---|---|---|---|
| Мастерская | 1–2 места | до 30 КП в месяц, рендеры пакетом | 2 990 ₽/мес |
| Салон | до 5 мест | без лимита КП, 100 рендеров | 7 900 ₽/мес |
| Сеть | до 15 мест, несколько салонов | роли, города, CRM | 19 900 ₽/мес |
| Фабрика + дилеры | фабрика и дилерская сеть | общий прайс, отчёт по дилерам, белая метка | от 50 000 ₽/мес или 1 500–3 000 ₽ за дилерский салон |

- **Подключение 30–150 тыс. ₽ разово:** загрузка и сопоставление прайсов, шаблон КП, наценки, обучение. Это реальная работа и отсекает «туристов».
- **Рендеры — пакетами** (себестоимость ~2–10 ₽ за картинку у шлюзов и российских моделей [оценка]), не в безлимит.
- **Год со скидкой 15–20 %.**
- Позже — доход от поставщиков (плиты, фурнитура), когда наберётся объём КП: «ваш прайс по умолчанию у 300 салонов».

Ориентиры рынка: Битрикс24 «Базовый» ~2 490 ₽/мес; мебельные CRM 2,5–30 тыс. ₽/мес; конструкторы КП 2–20 тыс. ₽/мес; лицензия Базис-Салон ~40 тыс. ₽ разово.

Грубая экономика на одного клиента «Салон» **[оценка]**: выручка 7 900 ₽/мес; затраты — хостинг ~300–500 ₽, рендеры 200–1 000 ₽, поддержка 1–2 часа в месяц. Маржа высокая; основная статья — подключение и поддержка, поэтому автоматизация импорта прайсов и проектов напрямую = прибыль.

## 6. Как выходить на рынок

1. **CULTURA — эталон (сейчас).** Довести пилот и замерить цифры «до/после»: время от проекта до КП, доля открытых КП, конверсия КП → договор, ошибки в ценах. Без этих цифр продавать нечего.
2. **2–3 дружественные компании бесплатно на 3 месяца** (лучше — работающие в Базисе и в К3, чтобы сделать адаптеры). Цель: подключение без участия разработчика за 1 день.
3. **Фабрики с дилерами.** Одна фабрика = десятки салонов. Предложение: «ваш прайс и бренд у всех дилеров, отчёт по КП».
4. **Каналы:** выставка UMIDS в Краснодаре (апрель 2027), «Мебель» в Экспоцентре; дистрибьюторы фурнитуры и плит (Boyard, MDM, «Аристо», Firmax, дилеры Egger/Kronospan) — им выгодно, чтобы их прайс был в инструменте у салонов; маркетплейс Битрикс24; мебельные форумы и Telegram-чаты; обучающие видео «из PRO100 в КП за 10 минут».
5. **Пилот за деньги:** 3 месяца за 50 % → цель 50 % пилотов переходят на тариф.

## 7. Дорожная карта продукта

**0–3 месяца — довести у себя и подготовить к продаже**
- Пилот CULTURA, замер цифр; спецификация и договор; Битрикс24.
- Единый формат проекта + адаптер PRO100 файлом; сопоставление «для всей компании».
- Разбор прайсов через ИИ (PDF/Excel → строки).
- Копии базы, мониторинг, журнал ошибок.

**3–6 месяцев — первые внешние клиенты**
- Несколько компаний в одной системе, регистрация, онбординг-мастер, конструктор КП в стиле компании, наценки по группам.
- Адаптер Базиса XML, настраиваемый адаптер Excel/CSV.
- Тарифы, оплата, оферта, документы по 152-ФЗ; отдельное юрлицо; заявка в реестр отечественного ПО.
- 2–3 пилотные компании.

**6–12 месяцев — масштаб**
- Режим «фабрика + дилеры», белая метка.
- Быстрый ввод модулями («прикидка»), черновик по PDF/скриншоту через ИИ.
- amoCRM, 1С; варианты в одном КП; декоры с картинками.
- Конфигуратор в браузере для типовых модулей фабрик (на базе «Конструктора кухонь»).

## 8. Риски и что с ними делать

| Риск | Что делать |
|---|---|
| Салоны не доверят прайсы и себестоимость продукту от фабрики-конкурента | Отдельное юрлицо и бренд продукта; в оферте — данные клиента принадлежат клиенту, выгрузка в любой момент |
| Подключение «съест» команду (у всех разные прайсы и названия) | Разбор прайсов ИИ, сопоставление, которое учится, платное подключение |
| Маленький средний чек | Фабрики с дилерами, пакеты рендеров, годовая оплата |
| Конкуренты закроют свой пробел (Базис сделает КП ссылкой, PlanPlace — импорт) | Скорость; ставка на «любая программа» и связку с CRM; глубина в продажах (аналитика КП, напоминания) |
| Рынок кухонь падает (−7,5 % в 2025) | Продавать как способ продавать больше теми же людьми: конверсия КП, скорость ответа |
| Нейросети за рубежом и персональные данные | В промпты не передавать данные клиента (уже так); переключатель «только российские модели» (Kandinsky, YandexART) |

## 9. Что сделать в ближайший месяц

1. Пилот у себя: 1–2 менеджера, 10 заказов, замер времени и ошибок (метрики — в `docs/ux-audit-2026-11.md`).
2. Решить: делаем ли продукт для внешних компаний (если да — отдельное юрлицо и имя продукта).
3. Найти 2 дружественные компании (одна в Базисе, одна в К3) и получить у них по образцу выгрузки проекта и прайса.
4. Я начинаю с «единого формата проекта» и сопоставления на всю компанию — это нужно и CULTURA (меньше ручного выбора), и продукту.
